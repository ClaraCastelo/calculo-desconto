Calculo de desconto - Projeto em python

Utilizou if e elif para analisar o valor da compra e aplicar o desconto corretamente
    
    Sendo 3 tipos de desconto:
    - 5% para compras até 199 reais
    - 10% até 299 reais
    - 15% para compras a partir de 300 reais

- Calculo do desconto:

  **porcetangem em forma de fracao * valor da compra**

- Calculo do novo valor: 
    
    **valor total da compra - desconto**
   
• Como executar o programa:
O usuario deve insirir o valor total da compra, o programa analisa a quantidade de desconto a se aplicada e fala ao usuario o valor a se pago como desconto aplicado.
